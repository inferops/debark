build screen — replay harness

A fake backend replays a recorded debark.events/v1 stream with the real emitter's timing: progress throttled to one event per 250 ms per file, concurrent downloads interleaved, one archive that sends no Content-Length (total_bytes: -1), one download that retries and rewinds its byte count, twelve store hits that download nothing, a redistribution warning in the first second and a doctor.finding before any bytes move. Pick an ending, fill in an output folder and signing key, accept the notice, and press Build bundle. There is no network access and no debark binary involved.

Progress events sets AppInfo.progress_events. Switch it to older debark and press Reset the screen to see the honest rendering when the located binary has no --json-events: no bar at all, a labelled spinner, an empty log, and a sentence saying so. It is read once on mount, so the reset is needed.
