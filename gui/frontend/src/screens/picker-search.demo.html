The component

Everything below the heading is createSearchField()'s el — and it is one row: a search box, one filter button, a result count. It used to be five rows holding four independent filtering mechanisms plus an “active filters” echo. The scope toggle, the application categories and the section list all live inside the filter popover now, and the button’s own label states what is filtered, which is why there is no longer an echo row for it to state.

Tab through it: search box, filter button, and that is the whole chrome. Open the popover (Enter or Space) and the category list is one more tab stop with arrow keys inside it — seventy categories are never seventy tab stops. Escape closes the popover and puts focus back on the button; Escape in the search box clears it and does not leave the field. The popover is a .df-popover, not a <details>: an inline disclosure above a virtualised list reflows it, which moves its scroll position and its keyboard cursor every time a filter is touched.
