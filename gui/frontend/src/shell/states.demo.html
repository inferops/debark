The module did not load

Chrome and Firefox refuse to load an ES module over file:// (its origin is null, so the module fetch fails CORS). The page itself is fine; only the import was blocked. Serve this directory over loopback and reload — for example python3 -m http.server in frontend/src/, then open http://localhost:8000/shell/states.demo.html. WebKit, which is what this app actually ships against, loads it straight from disk.

Loading

A spinner with no label is a bug, so loadingState throws without one. The bar is determinate when a fraction is known and indeterminate when it is not — and it is not known often, because total_bytes is -1 whenever a mirror sends no Content-Length.

A whole catalogue build, driven by events

One loadingState, updated with progressFrom(event) at the same 250 ms the backend actually throttles to. It walks the seven catalogue phases, switches between determinate and indeterminate mid-run (the download phase hits a mirror with no Content-Length), and is cancellable. Watch the announcement line below the panel: it changes on phase boundaries and 10 % steps, never on every tick.

Skeleton rows

Placeholders for a list that is loading. They use the library's own .df-skeleton-row, whose height is --skeleton-row-height — required to equal --row-height, which is the virtualiser's contract. Error — two sentences, details collapsed

The summary says what is wrong; the hint says what to do next. They are separate fields because the backend already produces them separately, and merging them into one blob wastes that. Raw stderr goes in a drawer that starts closed — this audience wants to read it, and does not want it in their face.

Escaping

Package descriptions, file paths and stderr all reach these helpers, and stderr can contain anything at all. There is no HTML-string path in the module: every node is built with createElement/createElementNS and every string lands in textContent. The error below was handed markup, a template-literal-looking string and a null byte; it renders them as characters.

What to check on this page

  • Both themes. Use the toggle top right; it sets data-theme on <html>, and removing it follows the system.
  • Reduced motion. With prefers-reduced-motion: reduce the spinner stops, the shimmer stops and the indeterminate bar goes still at full width — which is exactly why every one of these states carries words.
  • Keyboard. Tab through: every Cancel, Retry, Clear and Dismiss has a visible focus ring.
  • The console. This page makes no network request and loads no font, no icon library and no CDN. The only fetches are the two design-system stylesheets and states.js, all relative and all local.
  • The live region. It is visually hidden inside each loading state; the mirror under the live build panel above shows what a screen reader is being told, and when.
